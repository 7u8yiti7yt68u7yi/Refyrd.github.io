## Что внутри

- **Игровой хаб** — главная витрина выбора игр (`index.html`) с M3 карточками и общими отзывами.
- **Snake (Змейка)** — классический геймплей на HTML5 Canvas с поддержкой разного размера поля (маленькое, стандартное, большое).
- **Таблица рекордов** — глобальный онлайн-лидерборд на Firebase Firestore с синхронизацией рекордов.
- **Аккаунты и профили** — вход по Email/паролю, через Google или GitHub, возможность играть гостем и сохранять никнейм. Состояние авторизации синхронизируется между хабом и играми через cookies.
- **Система отзывов** — ветки отзывов с лайками, дизлайками, ответами и удалением только своих сообщений.
- **Кастомизация** — светлая и тёмная темы, 5 цветовых палитр (зелёная, синяя, красная, фиолетовая, нейтральная), шрифт Google Sans Flex.
- **Двуязычность** — переключение RU / EN на лету.
- **Управление** — клавиатура (WASD / стрелки) и свайпы на сенсорных экранах.

## Стек технологий

- **Фронтенд:** Vanilla JavaScript (ES6+), HTML5 Canvas, CSS3 (CSS Variables, Flexbox, Grid).
- **Шрифты и дизайн:** Material Design 3 Expressive, Google Sans Flex.
- **Бэкенд & БД:** Firebase Auth, Cloud Firestore (Security Rules v2).
- **Хостинг:** GitHub Pages.

## Управление в игре

| Действие | Клавиатура | Сенсорный экран |
|---|---|---|
| Движение | `W` `A` `S` `D` / Стрелки | Свайпы в нужную сторону |
| Рестарт | Кнопка «Заново» / `Enter` | Тап по кнопке |
| Пауза / Меню | Кнопка «Меню» | Тап по кнопке |

## Локальный запуск

Сборка не требуется, всё работает прямо из коробки:

```bash
# Клонировать репозиторий
git clone https://github.com/Refyrd/Refyrd.github.io.git
cd Refyrd.github.io

# Запустить любой локальный сервер, например:
npx serve .
# или
python -m http.server 8000
```

После этого открыть в браузере `http://localhost:8000`.
